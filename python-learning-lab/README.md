# Python Learning Lab

A compact test drive of the `geist-learning-lab` skill: one Python basics lesson built around prediction, immediate feedback, explanation, transfer, checkpoint, reflection, and local progress.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

The browser-side playground intentionally supports a safe subset of Python basics: assignments, numbers, strings, booleans, `+`, names, comments, and `print(...)`. It does not execute arbitrary local Python code.
